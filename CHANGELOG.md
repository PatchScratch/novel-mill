# Changelog

## 1.9.0 — 2026-10-07

- Packaging: `build_windows.spec` (onefile exe) and `build_linux.spec` + `packaging/appimage/` (AppImage) with tag-driven GitHub Actions building and attaching both to releases. The launcher resolves its tab modules inside a PyInstaller bundle, the splitter keeps user rules in the config dir when frozen, and `VERSION` is now the single version source for every module.
- App icon: a pencil-sketch Japanese stone mill (ishiusu) on the shared dark badge, generated by `tools/make_icon.py`. Assets in `assets/` (1024/512/256 PNG + multi-size `.ico`).
- Theme adopts the shared PatchScratch design language, based on Translation-Aggregator `gui/theme.py`: same palette tokens and hex values (window / pane / text / accent / button / input / border / handle), light-theme accent `#3b8ed0`, gray button hover, themed scrollbar handles, 10 pt base font.
- Mill and OCR worker threads marshal status/progress/button updates onto the Tk thread instead of touching widgets directly (fixes rare crashes mid-run).
- Mill: Temp and Timeout no longer overlap in the LM Studio panel; the token estimate counts Japanese at ~1 token/char; context overflow retries once with a minimal output budget; connection-refused gets the cooldown retry; empty in/out folders are rejected at Start.
- Mill: clicking below the last scene row no longer toggles it.
- Mill connection settings (API base, model, key, temp, timeout, pause, context, keep/overwrite) persist to `mill.json` in the config dir and reload on launch.
- Duplicated helpers consolidated into `wn_series.py` (read/write_text with the CP932/UTF-16 sniffer, safe_stem, nat_key, and the whole Tesseract OCR stack). The EPUB tab's stale PSM-6 OCR copy and its unwired add-images/OCR methods are deleted; tabs import from `wn_series` instead of keeping private copies.
- Image lists sort naturally (page2 before page10) on the OCR and EPUB tabs.
- EPUB: NCX (EPUB2) nav labels are parsed, so chapter files get real titles instead of spine filenames.

## 1.7.0 — 2026-09-22

- Display name is **Novel Mill** (WN and LN). Repo folder name unchanged.
- Mill pause default is 10 seconds.
- Mill skips `_break`, `p-00x` stubs, and bodies under 80 characters.
- Mill retries a timeout once; queue continues after Channel Error.
- EPUB tab refuses Adobe ADEPT / AES-encrypted EPUBs.
- Combine English shards → `english_full.txt`.
- README rewritten in plain English with a terminology list.
